# E-commerce-sales-analysis-python

## About the Project
This project explores an e-commerce sales dataset using Python. It focuses on analyzing sales performance, identifying trends, and presenting insights through visualizations.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Contents
- `Ecommerce_Sales_Analytics_Dashboard.ipynb`: Jupyter Notebook containing the analysis, visualizations, and key findings.
- `ecommerce_sales_1000_rows.csv`: Dataset used for the analysis.

## Key Highlights
- Analyzing sales and order data
- Exploring product performance
- Visualizing sales trends
- Calculating key business metrics
- Summarizing insights from the data

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries:
   `pip install pandas matplotlib jupyter`
3. Open the notebook in Jupyter Notebook.
4. Make sure the CSV dataset is in the same folder as the notebook.
5. Run the notebook cells.
